# Входящие задачи: скил `tasks` и CLI

Решение владельца 24.11.2026: короткие задачи по проектам приходят в Telegram, складываются
Markdown-файлами в приватный git-репозиторий, агенты читают их оттуда. Бот, классификатор
и исполнитель живут в отдельном проекте `task-inbox`. Здесь — только то, что касается
ai-workspace: скил и зависимость от его CLI.

## Why
Идеи и баги приходят вдали от Mac. Нужно, чтобы агент дома открыл список, взял задачу
и довёл до pull request, а не пересказывал её заново. При этом нельзя завязать работу
на бота или одного провайдера моделей: повторить правило независимости.

## What Changes
- Скил `skills/tasks/SKILL.md` (публичный): `tasks list` → выбор → `tasks show` → скриншоты →
  `tasks start` → ветка `task/<номер>-<slug>` в репозитории проекта → тесты и сборка →
  коммит → `tasks review` со ссылкой на PR или `tasks done`.
- Скил работает через CLI `tasks` из проекта `task-inbox`. Ставится на Mac командой
  `uv tool install --editable ~/Projects/ai/task-inbox`, лежит в `~/.local/bin/tasks`.
  Репозиторий ai-workspace CLI не содержит и не собирает.
- Скил не мержит и не пушит в основную ветку, берёт одну задачу за раз,
  при неясной задаче спрашивает пользователя.
- Новая спека `task-inbox`; `sync-agents.py` раскладывает скил по трём инструментам
  без изменений скрипта.

## Независимость
- Задачи — обычные Markdown-файлы в git. Без бота их можно читать и менять руками,
  без CLI — тоже: скил описывает чтение файлов напрямую.
- Скилу не нужен конкретный провайдер моделей: его выполняет любой из трёх инструментов,
  на любой модели шлюза, в том числе локальной. Со зрением — смотрит скриншоты,
  без зрения — читает описания из файла задачи.
- Бот, классификатор и исполнитель на критическом пути чтения и выполнения задач не стоят.

## Out of scope
- Сам бот, классификатор, исполнитель, развёртывание на сервере: проект `task-inbox`.
- Создание приватного репозитория задач и ключей Telegram: делает владелец.
- Автоматический мерж, запуск задач без подтверждения пользователя в интерактивной сессии.

## Impact
`skills/tasks/SKILL.md`, спека `task-inbox`. Скрипты, `litellm/` и конфиги инструментов
не меняются.
