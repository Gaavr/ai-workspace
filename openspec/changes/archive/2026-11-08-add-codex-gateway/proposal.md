# Codex через шлюз

Решения владельца 08.11.2026: уровни `smart` и `fast`, шлюз только для этого Mac,
персона выбирается на весь чат, модель — отдельно.

## Why
Codex сейчас работает только на подписке OpenAI. Через шлюз ему доступны те же модели,
что OpenCode: бесплатные, платные дешёвые, локальная. Это удобство, а не защита: отключат
доступ к Codex — пропадёт и он сам, работа продолжится в OpenCode.

## What Changes
- **Шлюз только для этого Mac.** LiteLLM слушает `127.0.0.1`, а не все интерфейсы.
  Секретный мастер-ключ из `.env` ему больше не нужен: `.env` читает любая программа этого
  Mac, то есть от локальных программ ключ не защищал, а от сети теперь защищает адрес.
  Вместо него — постоянный ключ-заглушка `sk-local-gateway`: без мастер-ключа LiteLLM 1.108
  сверяет ключи с базой, которой нет. Заглушка не секрет, её можно держать в конфигах
  OpenCode и Codex, и Codex App, запущенному не из терминала, ничего передавать не нужно.
- LiteLLM из `docker-compose.yml` по-прежнему берёт настоящий ключ из `.env`.
- `oc.sh` передаёт только ключи провайдеров.
- `sync-agents.py` пишет в свой блок `~/.codex/config.toml` провайдер `gateway`:
  `base_url` шлюза, `wire_api = "responses"` (другой Codex 0.167 не принимает,
  LiteLLM переводит Responses в chat сам), заглушка в заголовке `Authorization`.
- Профили `~/.codex/smart.config.toml` и `fast.config.toml`: провайдер `gateway`, модель —
  алиас уровня из `agents/targets.json` (тот же, что у OpenCode), окно контекста —
  из `model_info`. Запуск: `codex -p smart`.

## Decisions
- Персона выбирается на весь чат или сессию, модель — отдельно. Комбинированные профили
  «персона + модель» не нужны (решение владельца 08.11.2026).
- Профили на уровни, не на каждый алиас: сменил модель уровня в `targets.json` —
  Codex переехал вместе с агентами OpenCode (решение владельца 08.11.2026).

## Out of scope
- Open WebUI в Docker: у его LiteLLM из `docker-compose.yml` ключ остаётся.

## Impact
`scripts/gateway.sh`, `litellm/config.yaml`, `scripts/sync-agents.py`, `.env.example`,
README, дельты `tool-sync` и `model-gateway`.
