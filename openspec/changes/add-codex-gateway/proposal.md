# Codex через шлюз

Черновик. Требования уточнить перед реализацией.

## Why
Codex сейчас работает только на подписке OpenAI. Через шлюз ему станут доступны те же
алиасы, что и OpenCode: открытые модели, прямые провайдеры и локальная. Это удобство,
а не защита: отключат доступ к Codex — пропадёт и он сам, работа продолжится в OpenCode.

## What Changes
- `sync-agents.py` пишет в свой блок `~/.codex/config.toml` провайдер `litellm`
  (`base_url` шлюза, ключ из `LITELLM_MASTER_KEY`).
- Профили на алиасы: `codex -p <алиас>` запускает сессию на этой модели через шлюз.
  Профили лежат рядом с профилями персон, чужие профили не трогаются.

## Decisions
- Персона выбирается на весь чат или сессию, модель — отдельно. Комбинированные профили
  «персона + модель» не нужны (решение владельца 08.11.2026). Модель для сессии с персоной
  задаётся рядом: `codex -p <персона> -m <модель>` или выбором модели в приложении.

## Open questions
- Профиль на каждый алиас или только на уровни `smart` и `fast`?
- Codex App: проверить, что он видит провайдер и профили из `config.toml` так же, как CLI.
- Ключ: Codex читает его из окружения (`env_key`), а приложение запускается не из терминала —
  откуда оно возьмёт `LITELLM_MASTER_KEY`?
