# Копия проектов на внешнем SSD

Решения владельца 08.11.2026: копия на SSD, рабочие папки целиком, без секретов,
папки `Apps`, `ai`, `YT` из `~/Projects`, старые копии на SSD не трогать.

## Why
Полные репо с историей уже лежат на Mac, отключение GitHub их не заберёт. Риск в другом:
GitHub — единственная копия вне этого Mac. Сломается или пропадёт Mac одновременно
с отключением GitHub — копий не останется. Нужна вторая копия на другом носителе,
с незакоммиченной работой, а не зеркало для push.

## What Changes
- `scripts/sync-projects.sh` копирует `~/Projects/{Apps,ai,YT}` в
  `CodeProjects/Projects/` на SSD с той же раскладкой: рабочие папки вместе с `.git`,
  незакоммиченным и неотслеживаемым.
- Не копируется: сборочный мусор (`DerivedData`, `build/`, `.build/`, `node_modules/`,
  worktrees агентов) и секреты (`.env`, `.env.*` кроме `.env.example`, `mcpo/config.json`,
  ключи `*.p8`, `*.p12`, `*.pem`, `*.key`, профили `*.mobileprovision`).
- Копия — зеркало: удалённое на Mac удаляется и в копии, но не насовсем. Удалённое
  и прежние версии перезаписанных файлов уходят в `CodeProjects/Projects-deleted/<дата-время>/`.
- Старые копии на SSD (`xcode/`, `MyApps/`, `ai/`, `SwiftProjects/` …) остаются как есть:
  в `MyApps/Swift/Lucid Focus` есть код, которого нет на Mac.
- Запуск командой, `--dry-run` показывает изменения.

## Out of scope
- Зеркало на другом git-хостинге (Codeberg, свой Gitea).
- Папка `cjex` — решение владельца.
- Автозапуск при подключении SSD.

## Impact
`scripts/sync-projects.sh`, `README.md`, новая спека `repo-mirror`.
