# Зеркало репозиториев

Черновик. Решение владельца 08.11.2026: «сделаем потом». Требования уточнить перед реализацией.

## Why
`ai-workspace` и проекты лежат на GitHub. GitHub уже ограничивал аккаунты по стране.
Заблокируют аккаунт — пропадут и push, и доступ к истории с другой машины.

## What Changes
- Каждый репо из списка получает запасной remote и пушится в него тем же движением,
  что и в основной.
- Минимум — bare-репо на внешнем SSD. Дальше, по ответам на вопросы, — сторонний хостинг.

## Open questions
- Какие репо: только `ai-workspace` или все в `~/Projects`?
- Внешний хостинг: Codeberg, свой Gitea (где поднимать), или только SSD?
- Пушить в зеркало на каждый push (хук) или по команде?
- Нужны ли зеркалу issues и PR или только git-история?

## Impact
Новая спека `repo-mirror`, скрипт зеркалирования, README.
