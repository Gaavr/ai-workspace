## ADDED Requirements

### Requirement: Запасная копия истории
Каждый репо из списка зеркалирования SHALL иметь полную копию истории вне GitHub,
минимум — bare-репо на внешнем SSD.

#### Scenario: Аккаунт GitHub заблокирован
- **GIVEN** репо зеркалировался
- **WHEN** GitHub недоступен для аккаунта
- **THEN** репо клонируется из зеркала со всей историей и ветками
