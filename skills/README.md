# Скиллы

Переиспользуемые процедуры. Один формат для Claude Code, Codex и OpenCode.

## Структура

```
skills/имя-скилла/SKILL.md
```

Имя папки совпадает с полем `name` в шапке файла. Папки с `_` в начале (`_template`) не подключаются.

## Публичные и приватные

| Путь | В git | Для чего |
|---|---|---|
| `skills/` | да | процедуры без личных деталей |
| `skills.local/` | нет | рабочий контекст, внутренние договорённости |

При совпадении имён `skills.local/` перекрывает `skills/`.

## Как подключены

`scripts/sync-agents.py` ставит симлинк на каждый скилл:

| Куда | Кто читает |
|---|---|
| `~/.claude/skills/<имя>` | Claude Code, OpenCode |
| `~/.agents/skills/<имя>` | Codex, OpenCode |

OpenCode видит обе папки и схлопывает одинаковые имена.

## Формат

```markdown
---
name: имя-совпадает-с-папкой
description: Что делает и когда применять
---
Тело инструкции.
```

## Главное про description

Модель постоянно держит в контексте только описание. Тело подгружает,
когда решит, что скилл подходит. Значит в описании должны быть триггеры —
слова, которые встретятся в реальном запросе.

| Плохо | Хорошо |
|---|---|
| `Про тесты` | `Использовать когда нужно запустить тесты или разобрать падение` |
| `Стиль кода` | `Использовать перед написанием нового Swift-файла` |
| `Работа с git` | `Использовать при создании веток, коммитов и PR` |

## Что класть внутрь

Процедуру, а не рассуждение: что сделать, в каком порядке, чего не делать.
Скилл заменяет объяснение, которое иначе пришлось бы давать каждый раз.

Длиннее полутора страниц — скорее всего это два скилла.

## Создать новый

```bash
cp -R skills/_template skills/новое-имя
open -e skills/новое-имя/SKILL.md
python3 scripts/sync-agents.py
```

Не забудь поменять `name` в шапке на имя папки.

## Применить

Новый скилл — запустить `sync-agents.py`. Правка существующего видна сразу, ссылка ведёт в репозиторий.
Инструменты читают скиллы при старте, поэтому нужна новая сессия.

## Проверить

Спросить у агента: «Какие скиллы тебе доступны?» В OpenCode: `opencode debug skill`.
